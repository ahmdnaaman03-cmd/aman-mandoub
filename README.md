# 🛡️ Aman El-Mandoob (أمان المندوب) - النسخة المستقرة

نظام دفع ذكي يعتمد على رموز QR الديناميكية لتسهيل عملية التحصيل المالي للمناديب وربطها بمتاجر Shopify.

## 🚀 المميزات الجديدة
- **قاعدة بيانات SQLite:** استبدال ملفات CSV بنظام قاعدة بيانات حقيقي وأكثر أماناً.
- **QR Code ديناميكي:** توليد رموز دفع فريدة لكل طلب.
- **واجهة احترافية:** تحسين واجهات المندوب والعميل لتكون أكثر جاذبية ومناسبة للهواتف.
- **نظام تقارير:** متابعة حالة التحصيل اليومي بشكل فوري.

## 🛠️ كيفية التشغيل
1. تثبيت المتطلبات: `pip install flask qrcode pillow`
2. تهيئة قاعدة البيانات: `python init_database.py`
3. تشغيل التطبيق: `python app.py`
